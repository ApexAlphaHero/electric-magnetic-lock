What an update does

Fast-forwards the checkout at /opt/door_access/repo from the configured git remote, re-runs the installer from it, then restarts the door service. If the door service does not come back within a few seconds the update is rolled back automatically and the previous version reinstalled — the lock is never left unmanaged by a bad release.

It will not run if the checkout has local edits, and it refuses any git remote other than the configured one. This page can be removed entirely with "allow_update": false in /etc/door_access/web.json.
